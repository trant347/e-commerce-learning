DATA FLOW:
==========
1. User books appointment → Calendar Service
2. Calendar Service → Publishes to Kafka (bookings topic)
3. Worker Service → Processes → Publishes to Kafka (notification-events)
4. Notification Service:
   a. Consumes from Kafka
   b. Saves to MongoDB
   c. Pushes to connected SSE clients
5. Frontend (React):
   a. Fetches initial notifications (REST)
   b. Opens SSE connection for real-time updates
   c. Updates UI automatically
